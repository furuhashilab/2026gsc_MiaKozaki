# プロ野球開催による球場周辺地域の混雑変化 ― 有料人流データに依存しない行動分析の試み

---

## Abstract

プロ野球の試合日には、球場に数万人が集まり、試合の前後で一斉に人が動く。本研究では、試合開催が周辺店舗の混雑に与える影響を検討する。対象は横浜スタジアム周辺の24地点で、2026年8月のDeNA主催ナイター14試合について、Googleマップの「混雑状況」を30分ごとに記録した(計4,920件)。先行研究は人流データと試合のない日の比較を用いていたが、本研究のデータは店ごとの相対的な混雑ラベルであり、試合のない日のデータもない。そこで、試合終了時刻を0分にそろえ、混雑がどの時間帯に集中するかをヒストグラムで示し、業態や勝敗・終了時刻で比較する。現時点ではデータの収集と整形を終え、集計に着手している。観察の段階では、試合終了後に混み始める店や、試合前に混むコンビニが見られる一方、勝敗との関係ははっきりしていない。

## Introduction

### 背景

プロ野球の試合開催日には、数万人規模の観客が球場およびその周辺地域を訪れる。観客は試合前後に駅、飲食店、コンビニエンスストア、商業施設などを利用すると考えられ、試合開催は球場内部だけでなく、周辺地域の混雑や経済活動にも影響を与える可能性がある。



### 先行研究

観客動員そのものを予測する研究(近藤・朝日など)→ 球場の中に向かう人の話
経済効果・満足度を扱う研究(経済効果note、フードサービス調査など)→ お金や満足度の話で、時間的・空間的な混雑変化は扱わない
人流データ企業による実測レポート(LocationMind)→ 手法は近いが有料データ・単発レポートで、条件別の系統的比較はしていない


| | データ | 比較 | 出力 |
|---|---|---|---|
| 日本経済研究所ほか(2025)等々力スタジアム | 携帯基地局の人流データ、決済データ(推計人数・金額) | 試合日 vs 同じ月・同じ曜日の試合のない日の平均 | キックオフ基準の時間帯別折れ線に2本を重ねる/500mメッシュの増減(3D棒)/相関・重回帰 |
| 小林ほか(2019)イベント参加前後 | スマートフォンの位置ログ(Agoop) | イベント前 vs イベント後 | 1kmメッシュの滞留点分布図を前・後で並べる+重回帰(調整済みR²=0.025) |

どちらも、人数がわかる大規模なデータと、比べる相手の系列(試合のない日、イベント前)があることを前提にしている。これらの研究では携帯電話の位置情報など、大規模な人流データが用いられることが多く、詳細な人流データは有料である場合が多い。学生が個人で継続的に取得することは難しいため、本研究では有料人流データを用いる代わりに、無料または公開されている混雑指標や試合情報を定点観測し、スポーツイベント開催時の人の行動変化を分析する。


### 目的

本研究では、試合開催が周辺店舗の混雑に与える影響を検討する。

### 研究課題と仮説

| | 研究課題 | 仮説 |
|---|---|---|
| RQ1 | 試合の前後で、周辺店舗の混雑はどう変わるか | 試合中は通常より空き、試合終了後に混み始める |
| RQ2 | 業態によって混み方に違いはあるか | 居酒屋などの飲み屋系は試合終了後に混み、コンビニは試合前に混む |
| RQ3 | 勝敗や試合終了時刻によって違いはあるか | 勝った日は、試合後の飲み屋系がより混む |

## 2. Methods(方法)

1. **データ収集**
   2026年8月のDeNA主催ナイター14試合で、球場周辺24地点のGoogleマップ「混雑状況」を30分ごとに記録する。
   https://docs.google.com/spreadsheets/d/1LmpcLYxrAfFwXWrOBIVeD0kyc0YqmMFbuUiWOCUoLZ0/edit?gid=2059511948#gid=2059511948
   
3. **データ整形**
   記録を「1行=1地点×1日×30分」の形に作り直し、混雑ラベルを数値にする(混んでいる +1/通常 0/混んでいない −1)。
4. **時間軸の統一**
   試合ごとに終了時刻が違うため、各観測に「試合終了から何分か」を付け、終了時刻を0分にそろえる。
5. **比較・分析**
   30分ごとの混雑の分布をヒストグラムで示し、試合の前後(RQ1)、業態(RQ2)、勝敗・終了時刻(RQ3)で比べる。

### データの概要

| 項目 | 内容 |
|---|---|
| 試合日 | 2026年8月 4・5・6・7・8・9・18・19・20・21・23・28・29・30日(8/22は中止) |
| 対象地点 | 24地点(居酒屋・レストラン・中華 12 ／ ファストフード 5 ／ コンビニ 3 ／ カフェ 3 ／ 公園 1) |
| 記録間隔 | 16:00〜試合終了の2時間後まで、30分ごと(観測数 4,920件) |
| 記録した内容 | Googleマップの「混雑状況」(通常より混んでいる / 通常 / 通常より混んでいない / 営業時間外) |
| 試合情報 | 開始・終了時刻、スコア、勝敗(8月日程表) |
| ツール | Python(整形・集計)、QGIS(地図化)、GitHub(データとコードの管理) |

データの整形は、デジタル庁「機械判読可能なデータの表記方法の統一ルール」を参考にした(セル結合なし、1セル1値、1行1レコード)。

本研究のデータは人数ではなく、店ごとの相対的な混雑ラベルである。試合のない日のデータもないため、先行研究のように2つの系列を重ねて差を見ることはできない。そこで、試合終了時刻を基準に、混雑がどの時間帯に集中しているかを見る。

## 4. Discussion(考察)

### 課題

- **比較の基準**:試合のない日のデータは取れないため、試合日の中で「試合前・試合中・試合後」を比べる形にする。基準はGoogleの「通常」(その曜日・時間帯の平常値)。
- **「通常」の意味**:Googleの平常値との相対比較であり、来店者数そのものではない。平常値に過去の試合日が含まれている可能性もある。
- **利用規約**:Googleマップの利用規約には、コンテンツの大量取得や再配布を禁止する条項がある。本研究では目視での記録・研究目的に限定し、論文でもその旨を明記する。
- **データ品質**:1地点で記録パターンが不自然に規則的であり、入力ミスの可能性があるため確認中。

### 今後の予定

1. 試合終了時刻を基準にしたヒストグラムを作る(まず居酒屋・飲み屋系から)
2. 勝ち/負け、終了時刻、曜日で分けて比べる
3. 居酒屋系でまとまったら、ファストフードなど他の業態に広げる
4. 天気・気温・周辺イベントをどこまで考慮するか決める
