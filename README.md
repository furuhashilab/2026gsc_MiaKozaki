# プロ野球開催による球場周辺地域の混雑変化 ― 有料人流データに依存しない行動分析の試み

---

## 構想発表エレベーターピッチ

ホームチームが勝った夜、球場周辺の店は普段よりどれくらい賑わうのかを、お金をかけずに調べます。

イベント時の人の動きを分析する研究では、通常は携帯電話の位置情報に基づく高価な人流データが使われますが、学生が継続的に使うのは費用面で困難です。

そこで本研究は、Google Mapsなどの無料の混雑指標と、試合日程・勝敗・気象データを組み合わせます。試合開催日と非開催日、勝利日と敗北日、デーゲームとナイトゲームで球場周辺の混雑がどう変わるかを定点観測し、比較します。

無料で公開されている情報だけで、イベント時の人の行動変化をどこまで捉えられるか。その可能性と限界を示すことが、この研究のゴールです。

---

## Abstract

本研究は、プロ野球の試合開催が球場周辺地域の混雑状況に与える影響を、試合開催日と非開催日、およびホームチームの勝利日と敗北日の比較から明らかにすることを目的とする。

従来、イベント開催時の人流や周辺地域への波及効果を分析する研究では、携帯電話の位置情報などに基づく有料の人流データが利用されることが多い。しかし、学生による継続的な研究では、費用や利用条件の面から使用が難しい。

そこで本研究では、無料または公開されている混雑指標、プロ野球の試合日程・開始時刻・終了時刻・勝敗・観客数、気象データおよび地理空間データを組み合わせ、球場周辺の駅、飲食店、商業施設などの混雑状況を時系列で分析する。試合開催日と非開催日の比較に加え、勝利日と敗北日、デーゲームとナイトゲーム、平日と休日などの条件別比較を行い、結果はグラフおよびGISを用いて可視化する。

本発表では、研究の背景・目的・方法と、混雑データの取得可能性に関する予備的な確認状況を示し、今後の検証課題を提示する。

## Introduction

### 背景

プロ野球の試合開催日には、数万人規模の観客が球場およびその周辺地域を訪れる。観客は試合前後に駅、飲食店、コンビニエンスストア、商業施設などを利用すると考えられ、試合開催は球場内部だけでなく、周辺地域の混雑や経済活動にも影響を与える可能性がある。

先行研究では、スポーツ施設への来訪が周辺の飲食・宿泊施設や小売店への訪問を増加させることが報告されている(Abbiasov & Sedov, 2023)。また、スポーツイベントなどの特別なイベントが、通常時とは異なる公共交通機関や周辺施設の混雑パターンを生み出すことも研究されている(Hu et al.)。

一方で、これらの研究では携帯電話の位置情報など、大規模な人流データが用いられることが多く、詳細な人流データは有料である場合が多い。学生が個人で継続的に取得することは難しいため、本研究では有料人流データを用いる代わりに、無料または公開されている混雑指標や試合情報を定点観測し、スポーツイベント開催時の人の行動変化を分析する。


### 仮説

- **H1**：ホームチームが勝利した日は、敗北した日よりも周辺飲食店などへの滞留が長くなる。
- **H2**：デーゲームでは試合終了後に周辺地域へ滞在する傾向が強く、ナイトゲームでは駅へ移動する傾向が強くなる。
- **H3**：球場から近い施設ほど試合開催の影響を強く受けるが、施設の種類によって影響の大きさは異なる。

### 意義

- プロ野球開催による周辺地域の混雑変化を、時間的・空間的に可視化する
- 試合開催の有無だけでなく、勝敗・試合時間・曜日・天候などの条件を組み合わせ、人の行動変化を分析する
- 有料の人流データを使用せず、学生が取得可能な情報から人の行動を分析する方法の可能性と限界を検討する

## Methods

### 対象地域

対象球場を1か所選定し、球場を中心とする一定範囲を分析対象地域とする。

候補：**横浜スタジアム**とその周辺の以下の地域・施設

- 関内駅 / 日本大通り駅 / 石川町駅
- 横浜中華街
- 周辺の飲食店・コンビニエンスストア・商業施設・公園広場

対象施設は、球場からの距離・施設分類・営業時間などを考慮して選定する。

### 比較条件

| 分類項目 | 区分 |
|---|---|
| 試合開催 | 開催日／非開催日 |
| 試合結果 | 勝利／敗北／引き分け |
| 開始時刻 | デーゲーム／ナイトゲーム |
| 曜日 | 平日／休日・祝日 |
| 天候 | 晴れ／曇り／雨 |
| 観客数 | 実数または複数区分 |
| 試合時間 | 開始・終了時刻、所要時間 |

非開催日は、比較対象となる試合日と曜日・時間帯・天候などが近い日を選定する。デーゲーム/ナイトゲームと平日/休日は独立ではないため、分析時には両者を組み合わせたクロス集計または回帰分析により交絡を分離する。

### データソース

| データ種別 | 内容 |
|---|---|
| 試合データ | 試合開催日、開始・終了時刻、勝敗、観客数、対戦相手、得点差 |
| 気象データ | 天候、気温、降水量、風速 |
| 地理空間データ | OpenStreetMap、国土地理院地図、駅・道路・歩行者経路・店舗の位置情報、球場から各観測地点までの距離 |
| 混雑データ | Google Mapsなどで無料閲覧できる混雑指標(候補) |

### 観測時間

試合開始3時間前／2時間前／1時間前／試合中／終了直後／終了30分後／終了1時間後／終了2時間後、の9時点を基本とする。試合終了時刻は試合ごとに異なるため、固定時刻に加えて試合終了時刻を基準とした相対時間でも記録する。非開催日は、比較対象となる試合日と同じ曜日・時間帯を観測する。

### 分析手順

1. 対象球場と観測施設を選定する
2. 各観測施設を、駅・飲食店・商業施設・コンビニエンスストアなどに分類する
3. 試合開催日と非開催日の混雑状況を記録する
4. 試合情報・天候・曜日などを記録する
5. 観測地点ごとに混雑状況の時系列変化を整理する
6. 開催日と非開催日、勝利日と敗北日などを比較する
7. 球場からの距離や施設分類との関係を分析する
8. 結果をグラフおよびGIS上の地図として可視化する
9. 得られた混雑パターンから、球場周辺における集団的な行動傾向を考察する

### 使用ツール

- Google Sheets / Excel：データ記録・整理
- Python：集計、統計分析、グラフ作成
- QGIS：観測地点および分析結果の地図化
- GitHub：研究過程、データ、コード、成果物の公開

### 方法上の留意点(現時点で把握している限界)

- Google Mapsの混雑指標は利用規約上、自動スクレイピングができないため、記録は手動での定点確認に限られる。また指標が表示されるかどうかは施設種別によって異なる可能性があり、対象施設ごとに事前確認が必要
- Google Mapsの混雑度は数段階の粗い指標であり、実数としての人流データではない。したがって「観客が特定の店舗へ移動した」と断定するのではなく、複数地点の混雑状況の時間変化から集団としての行動傾向を推定するものと位置づける
- 1試合あたり8時点×複数施設の手動記録は工数が大きいため、まず試験観測により実際の所要時間・取得可能性を確認したうえで本観測の規模を決定する
- 観客数などの公式発表値は概算である場合が多く、実測値ではない点に留意する
